- **Licence:** MIT, Copyright (c) 2026 DietrichGebert. Full text in `.claude/skills/ponytail/LICENSE`.

## ADL SCORM 1.2 schema files

- **What:** the four XML schema files of the SCORM 1.2 content package (`adlcp_rootv1p2.xsd`,
  `ims_xml.xsd`, `imscp_rootv1p1p2.xsd`, `imsmd_rootv1p2p1.xsd`), kept unchanged apart from line
  endings in `packages/exporters/schemas/scorm12/`. Every SCORM 1.2 package we export carries them
  beside its `imsmanifest.xml`, as the standard expects.
- **Source:** published by ADL with SCORM 1.2 (IMS Content Packaging 1.1.2 and IMS Meta-data 1.2.1
  are copyright IMS Global Learning Consortium; the ADL extension schema is ADL's). Taken from the
  npm package `simple-scorm-packager` 0.2.7 (MIT), folder `lib/schemas/definitionFiles/scorm12edition`.
- **Licence:** the files carry their copyright notices and no licence text. They are the standard's
  own schema set, redistributed inside SCORM packages by every authoring tool.

## ADL SCORM 2004 4th Edition schema files

- **What:** the seventeen schema files of the SCORM 2004 4th Edition content package
  (`adlcp_v1p3.xsd`, `adlnav_v1p3.xsd`, `adlseq_v1p3.xsd`, `imscp_v1p1.xsd`, `imsss_v1p0.xsd` and
  the ten `imsss_v1p0*.xsd` files it includes, `xml.xsd`, `XMLSchema.dtd`, `datatypes.dtd`), kept
  unchanged apart from line endings in `packages/exporters/schemas/scorm2004/`. Every SCORM 2004
  package we export carries them beside its `imsmanifest.xml`, as the standard expects.
- **Source:** published by ADL with SCORM 2004 4th Edition (IMS Content Packaging and IMS Simple
  Sequencing are copyright IMS Global Learning Consortium; the ADL extension schemas are ADL's;
  `xml.xsd` and its DTDs are W3C's). Taken from the npm package `simple-scorm-packager` 0.2.7 (MIT),
  folder `lib/schemas/definitionFiles/scorm20044thedition`.
- **Licence:** the files carry their copyright notices and no licence text. They are the standard's
  own schema set, redistributed inside SCORM packages by every authoring tool.
- **Not included:** the IEEE LOM schema files that `metadata.xml` could point at. Their licence is
  CC BY-SA, so they wait for a licence decision; `metadata.xml` names the LOM namespace without a
  schema location until then.

## FFmpeg n9.0.2 (downloaded by the desktop app, not included)

- **What:** the media converter the desktop app uses to turn audio and video that is not web-ready
  into WebM (VP9 and Opus) and MP3 (D-12, D-43; M2-13). It is **not in this repository, the app or
  its installer**: the first time an author adds such a file, the app asks, then downloads the
  build below, checks its SHA-256, keeps it in its own data folder and runs `ffmpeg.exe` as a
  separate program with its own shared libraries (`apps/desktop/src-tauri/src/media.rs`).
- **Build:** BtbN FFmpeg-Builds, Windows x64 LGPL shared build of FFmpeg n9.0.2-17-g2a571b6068,
  release `autobuild-2026-09-30-13-08`; address, size and SHA-256 pinned in
  `apps/desktop/src-tauri/media-tool.json`.
- **Source:** FFmpeg commit 2a571b6068 (https://github.com/FFmpeg/FFmpeg/commit/2a571b6068) and
  the build scripts at https://github.com/BtbN/FFmpeg-Builds. The download carries its licence
  (`LICENSE.txt`) and the licences of the libraries it is built with.
- **Licence:** LGPL-3.0-or-later (configured with `--enable-version3`, without GPL or non-free
  parts). The licence gate accepts LGPL for downloaded programs and refuses GPL
  (`tools/licence-gate`).
