# @course-suite/blocks-editor

The blocks editor's screens (M2-08 onward, BLK-01): runtime-neutral React that reaches files,
dialogs and the window only through `@course-suite/host` (ADR-0006), edits courses only through
`@course-suite/doc-ops` commands, keeps them in `@course-suite/project` files and draws everything
with `@course-suite/ui` and its string catalogue. Apache-2.0, layer `ui`. `apps/desktop` runs it
over the desktop host; `apps/web` serves it at `editor.html` over the in-memory host for the
browser tests.

```tsx
import "@course-suite/ui/styles.css";
import "@course-suite/blocks-editor/styles.css";
import { BlocksEditorApp } from "@course-suite/blocks-editor";

createRoot(element).render(<BlocksEditorApp host={host} locale="en" />);
```

## What it does

| Part | Behaviour |
|---|---|
| Dashboard (blocks-editor.md H6 to H14) | Course cards with a placeholder cover, title, type, lesson count and last change, 16 to a page with a paging bar (H14, UI-BLOCKS-EDITOR-R3); new blank course or microlearning, or one from a placeholder template (below) (title, then where to save the `.crs`, then the editor); open a `.crs` through the open dialog; search by title as you type, type filter, sort by last updated, date created or title (remembered, UI-BLOCKS-EDITOR-R2), grid or list view (remembered); select boxes, Ctrl/Cmd+A for every card on the page and a selection toolbar (delete; in Deleted, restore and remove), cleared on a new page (H10, 5.1); empty state on first launch |
| Card actions | Duplicate (name, then where to save; new ids, media copied), rename (the course title, saved into its file), delete to the Deleted list with an undo notice; Deleted: restore, remove from the list, empty Deleted. The app never deletes a file. A card whose file is gone says so and can be removed. Rename or duplicate of a course left with crash autosaves, and copying a lesson into one, first asks which work to use, as opening does |
| Opening | `openProject` with crash recovery: autosaved work newer than the file is offered (recover it, or open the saved file and drop the autosaves); a damaged or newer-version file is refused with its problems and left unchanged |
| Saving | Autosave 3 s after an edit, gathering the edits in between (`AUTOSAVE_DELAY_MS`; BLK-01 allows 10 s of loss); Ctrl/Cmd+S (also inside text: Ctrl/Cmd+S saves; strikethrough is Ctrl/Cmd+Shift+X, lead decision) or the save button writes the file (`saveProject`); Save as (Ctrl/Cmd+Shift+S) writes a new file and goes on editing it, leaving the old file at its last save; one write at a time |
| Leaving | Back to the dashboard, or the window's close button, first puts what the text fields hold into the course, then asks Save, Don't save or Cancel when there are unsaved changes; Don't save drops the autosaves |
| Editor frame (C1, C2) | Top bar: back, course title, save state (a live status), undo and redo (UI-BLOCKS-EDITOR-R14; Ctrl/Cmd+Z, Ctrl/Cmd+Y, Ctrl/Cmd+Shift+Z outside text fields), save, save as, Theme and Preview (below); Publish shown disabled until M2-18. The window title names the course, with `*` while unsaved. Undo history belongs to one screen: opening a lesson or going back clears it (UI-BLOCKS-EDITOR-R15) |
| Overview (C2, 2.2) | Course title (100 characters, UI-BLOCKS-EDITOR-R13), the source language code (default en-US, stored in canonical form), the author shown to learners (empty hides it), the description (formatted text, below), then the outline; a microlearning shows its one lesson instead of an outline |
| Text fields (R13) | Every text field of the course, plain or formatted (`DraftField` and `RichDraftField` in `fields.tsx`), saves while typing: the text reaches the course after a 500 ms pause, at least every 2 s while typing goes on, and on Enter, on leaving the field, and before saving, save as, leaving the course, closing the window, copying a lesson or blocks to another course, or switching lesson (`CourseSession.commitDrafts`). One editing of a field is one undo step; Escape takes it back. Text a field was given is never rewritten until the author edits it |
| Outline (C4 to C10, W4, W5, BLK-02) | One reorderable list of section headers, lessons and quizzes. A title field under it adds a lesson on Enter and a section header on Shift+Enter (UI-BLOCKS-EDITOR-R9); its Add menu adds a lesson, a quiz, a header or a lesson from a placeholder template (W3 step 3, C7). Each row: drag handle, its type icon when it has content (R11), title renamed in place, Open, a bin for headers and empty lessons (R12), and a menu: open, duplicate (lands below, R10), copy to another course, add a lesson, quiz or header below, move up or down, delete. Deleting shows a notice with undo for 8 seconds; buttons that go to the deleted lesson go in the same undo step (D-36). A section folds its lessons away and moves with them. Rows move by pointer drag, by keyboard drag (Enter on the handle, arrows, Enter) or by the menu, and every move, add and duplicate is announced |
| Copy to another course (C8, W5) | Pick one of the other listed courses (not a microlearning, which holds one lesson and no quiz; doc-ops refuses that copy too); the lesson goes to the end of its outline with new ids and its media files, and that file is saved; a notice offers to open it. When a crash left autosaved work in that course, the author first chooses which work to copy into, as for rename; cancelling copies nothing. Buttons to other lessons and a quiz's skip-ahead are left out; a lesson with a custom block is refused with a message |
| Lesson (L1, C11) | A lesson switcher (another lesson or quiz, or back to the overview, where focus returns to the lesson's row), the lesson's title, description (formatted text) and the author shown on it (empty: the course author), and its blocks (below). A quiz says its questions come later (M2-15). A microlearning edits its one lesson's blocks on the overview |
| Blocks (L1 to L6, W7 to W12) | One row per block: its type (a text block switches between its sibling types, keeping its content: W8, UI-BLOCKS-EDITOR-R25), its tools (style, format, move up and down, duplicate below, delete with an undo notice, and a menu to copy, paste below, insert below or copy a link to the block) and its content edited in place, with the block as the player's own renderer draws it beside the fields (BLK-03; `block-preview.tsx`, loaded with the first lesson opened). An insert control sits under every block and above the first; the shortcut bar at the end adds a paragraph with heading or a continue block, opens all blocks, and pastes. Rows move by pointer drag, by keyboard drag (Enter on the handle, arrows, Enter) or by the move buttons. Every change is one doc-ops command list (one undo step) and is announced (moved, added, duplicated, pasted) |
| Block library (L3, L4) | Every block type of blocks-editor.md 3 by category, searchable; the types the player shows today insert with sample content (every text and static block, below; knowledge checks: single choice, multiple response, fill in, matching; continue); the others say they are not available yet. With blocks copied, it pastes them where it was opened |
| Block content | Headings and subheadings as plain text, body text as formatted text (below), the content of the text and static blocks (below), a continue block's own label and hint, and a knowledge check's question, answers and right answers (single choice keeps exactly one). Adding answers and feedback comes with M2-15 |
| Text and static blocks (BLK-04, rise.md 3C, 2.5, 2.7 to 2.11, 2.14; `static-blocks.tsx`) | Paragraphs and headings with a heading level of 2 to 6 for the page outline (levels that would skip one below the heading above are not offered, and a heading left too deep by a move or a deletion is flagged in its fields and in the format menu; learners get the deepest level that keeps the outline, `headingOutline` in the format), body text in one to three columns and the space after the heading; columns (two to four, each with text and an optional picture); a table edited cell by cell (header row or none, rows and columns added or removed at the end; each cell a formatted text field, so a cell keeps its bold, italics and links and editing one leaves the others as they were), with cell padding; statements in four looks (plain, framed, ruled, bold; the rule's thickness and space) and a note (size, colour and its text, icon and its colour, corner rounding); quotes in four looks, over an image (alignment, overlay colour and strength) and a quote carousel (our own option: the look of every quote in it); each quote with its text, the name and a photo (shown or not, its size), a quotation mark, a rule above the name (its thickness) and the space above the name; numbered, bulleted and checklist lists with items added, moved and removed, the space after the marker, the marker colour and the number's text on it, and the first number; centred, full-width, beside-text (side and size), text-on-image (overlay) and banner images, and carousel or two-, three- and four-column galleries, each with zoom on click and corner rounding where the picture does not fill the page, and an image's link to a web page or a lesson (2.10; a linked picture opens its link instead of enlarging); line, numbered (counting on, or starting again at a number) and space dividers. Siblings switch keeping their content and settings (W8, UI-BLOCKS-EDITOR-R25). Settings at their default are left out of the file |
| Pictures (W15, 2.10, 2.17, BLK-04, BLK-05; `ImageSlot` in `static-blocks.tsx`) | One picture slot for every block and item that holds a picture, and for the cover and lesson header images: choose a picture in the open dialog or drop it (the media intake, below), replace it (the new one has no alt text yet) or remove it; the picture's name, its alt text and a decorative choice (empty alt text); a picture with neither is flagged under its alt text field. A gallery also takes several pictures at once, each a picture of its own after the others |
| Placeholder templates (rise.md 2 flow 1, 3J; H15, W3, GB-O6; D-38; `templates.ts`) | New: a starter course (two sections; introduction, explain an idea, teach the steps, summary) or a microlearning (one idea, explained); the outline's Add menu adds a lesson from four lesson templates. Every block holds our own placeholder text that says what to write, from the string catalogue, with new ids |
| Formatted text (L11, L13, 2.6, W14) | `RichTextField` from the kit with its tools while in use: paragraph style (normal, headings 2 to 5, UI-ACCESSIBILITY-R35), bold, italic, underline, strikethrough, subscript, superscript, bulleted and numbered lists, links to web and mail addresses, to a lesson or quiz found by its title (UI-BLOCKS-EDITOR-R33) or to a block (a copied block link), clear formatting; Ctrl/Cmd+B, I, U and K, and Ctrl/Cmd+Shift+X (Ctrl/Cmd+S saves; strikethrough is Ctrl/Cmd+Shift+X, lead decision), each named in its tool's tooltip and accessible description; Alt+F10 to the tools, Escape back. What a course file holds is cleaned to the format's allow-list (`cleanRichText` in the kit) before it enters the page, and what is typed or pasted is cleaned the same way before it is kept: only the format's elements and attributes (`RICH_TEXT_ELEMENTS`), b to strong, i to em, strike to s, no style |
| Style and format (L9, L10, 2.4, W10, W11) | Style: background light (default), gray, dark, black, the theme colour, the theme tint, a custom colour with automatic, light or dark text, or an image (M2-13, below); for blocks with item cards, keep cards white (on by default); an accent colour of the block's own, which the player uses only where it keeps 4.5:1 on the block's surface; an accent that does not is flagged with the nearest colour that does on offer. Format: padding presets small 15, medium 30 and large 60 px, or top and bottom from 0 to 200 px by slider or typed number, linked by default (UI-BLOCKS-EDITOR-R18); content width narrow, full column (default), wide or full width; the entrance animation (on by default for blocks other than text, rise.md 3D); in a microlearning, show with the next block in one step (BLK-03; the player's stepped mode comes with M2-16) |
| Copy and paste (W12, W13, rise.md 3J) | Copy a block (its menu, or Ctrl/Cmd+C on its row) or the blocks picked in manage blocks; paste below a block (its menu, or Ctrl/Cmd+V on its row), at the end, or where the library was opened, in any lesson of this course or of another course opened later. The app keeps the copied blocks with their media files; a paste gets new ids and the media index entries and files the course lacks (UI-BLOCKS-EDITOR-R24) |
| Manage blocks (L16, W12, W13) | Every block of the lesson to pick from (Space, click or select all); the picked blocks move as one by drag, take one background, are copied, copied to the end of another lesson of this course or to the end of the last lesson of another course or microlearning through a picker, with a notice that opens it (B7, B8, UI-PUBCOLLAB-R31), duplicated below the selection or deleted after a question, each one undo step |
| Theme (T1 to T10, 2.18, W20, BLK-09) | The top bar's Theme opens a menu of sections beside the course in the real player, which shows every choice as it is made: layout style (classic, rounded, bold: sets the cover and lesson header layouts only, keeping colour, fonts and navigation, UI-BLOCKS-EDITOR-R43), cover page (picture on the left or right, title over the picture with a dark, light or theme overlay and its strength, no picture; a crop of the cover picture; a logo chosen through the media intake (below) with its alternative text, crop, size small 1x, medium 1.5x or large 2x, and an optional square; start button, authors, which off hides the author on every lesson too (W6), skip the cover in published courses), lesson headers (courses only: hide, which greys out the rest and keeps the title for screen readers, R46; background light, gray, theme, tint, dark, black, a colour of the author's with its text, or a picture with its alternative text and crop under a dark, light or theme overlay, dark at 60 % by default; height; lesson count; author), colours (six suggestions or a hex colour, eyedropper where the browser has one, contrast auto, light or dark), fonts (the learner's device fonts, the default, so a course carries no font files until the author picks one; recommended pairings, or heading, body and interface fonts from the device's, the bundled ones and the author's own) and blocks (entrance animation, block and button corners). Each section saves as one doc-ops command list (one undo step: a new picture's media index entry goes in with the theme that uses it) or is cancelled. Pictures (`theme-images.tsx`) come through the same picker as every other picture and are stored under their content hash; a crop is a rectangle in the theme, which the player draws, so SVG and GIF are not cropped (2.18). A lesson's own switch hides its author on that lesson only (W6). Every colour is checked against WCAG AA as it is picked: text at 4.5:1 and theme-coloured buttons at 3:1 (rise.md rule 18), a cover overlay strong enough for its text over any picture; where one fails the panel says so and offers the nearest colour or strength that passes |
| Author's fonts (T9, W21, R48) | `FontLibrary` (`fonts.ts`): fonts the author adds (a name, a WOFF or WOFF2 file for the regular face, optional bold and italic, 5 MB each) with a notice that their licence is the author's responsibility, kept in the app data folder through the host (`fonts/<id>/<face>.<format>`) and listed in its storage, usable in every course. The block previews and the course preview draw with the theme's fonts |
| Preview (P1, W23, 2.20) | The top bar's Preview shows the course in the real player (`PreviewPane`, M2-11) from the lesson being edited, at computer, tablet or phone width; Edit goes back to the editor at the lesson on show (UI-BLOCKS-EDITOR-R52) |
| Media intake (M2-13, L17, W15 to W17, 2.17; `intake.tsx`, `media.ts`) | Files come in through the host's open dialog or by dropping them on a block's drop zone, and go into the project's content-addressed store: the same file added twice is kept once, under one key and one media index entry. Type is checked by extension and, for images, by content; files over 2 GiB are refused (below); every refusal is listed in one notice. Images larger than 1920 px on their long side are scaled down with the browser's canvas unless the author keeps the original quality; BMP becomes PNG; SVG and GIF stay as they are. Audio and video that are web-ready (MP4 with H.264 and AAC, WebM, MP3, M4A with AAC) go straight in; others go to the host's converter (D-12, D-43): the first time, the author is asked before it is downloaded; download and conversion are jobs (`@course-suite/jobs`) with a progress dialog and cancel. A host without a converter (the browser) asks for a web-ready file instead |
| Multimedia blocks (M2-13, 2.5, 2.12; `media-fields.tsx`) | Audio: the clip, caption, transcript and forward seeking (off makes it requirable, UI-BLOCKS-EDITOR-R37). Video: the clip, caption, caption tracks, transcript, thumbnail, forward seeking, corner radius and the course's video speed setting. Web embed: a link or embed code from YouTube, Vimeo, Loom or Dailymotion (D-44, `embed.ts`, no lookup service), caption and border. File to download: the file, its name and size, a description. Code snippet: the code exactly as typed, its language's name and a caption; in the format menu, word wrap and the snippet's colour with automatic, light or dark text (text only: no syntax colours). Their settings, with their defaults, are the format's (`variantSettings`). The style menu takes an image background with a dark (default, 50 %) or light overlay (2.4, UI-BLOCKS-EDITOR-R22) |
| Captions (ENG-07, BA4, BA5, W19, W20, D3; `captions.tsx`) | Any number of WebVTT tracks per video, one per language code; a file without the WEBVTT header or with bad times is refused, and markup the course does not keep is dropped (B5). A copy of each track can be saved where the author picks (B5). | Narration (rise.md 3D, W16, 2.4; `narration.tsx`) | Every block but headings and subheadings gets a narration button: an audio file, its transcript, and the player at the top or the bottom (default) |
| Cover and header images (D-38, 2.2, T4, T6, H8; `cover.tsx`) | The overview takes the course cover and a lesson its header image, each with alt text or the decorative mark; learners see a lesson's header image in the image layout of lesson headers only (2.18), which the field says under any other layout. Saving or opening a course keeps a copy of the cover at most 480 px wide in the app data folder (`covers/<storage key>`), which its dashboard card shows |

The course list lives in the host's storage (`library`), with what each card shows, so the
dashboard never reads the course files; on launch it only asks the host when each file last
changed (`HostFiles.modified`), which also tells which are gone.

`CourseSession` (one open course: editor, autosave, save, discard, save state, media for the preview
and media files pasted from another course) and the session's change events are what later editor
screens build on.

## Block types

`blocks.tsx` lists every block type with what it brings (the BLK-03 block-type contract): its
library group and name, `create` (a new block with sample content, from the string catalogue),
`Fields` (its content, edited in place through doc-ops commands), `Format` (its own options, shown
in the format menu after the common ones) and `switchable` (sibling types it can turn into, keeping
its content). The text and static types live in `static-blocks.tsx`; their settings, with their
defaults, are the format's (`variantSettings`). A type without `create` is listed as not available yet. A
later block epic adds its type there; the lesson, the library, copy and paste, manage blocks and
the style and format menus take it as it is.

video chapters (2.12; M2b); recording narration in the app (W16; M2b); a code snippet's syntax
colours and advanced editor (2.5; M2b); SRT, SBV and SUB caption files (ENG-07 in full; with

## Size

Built for the browser (`pnpm --filter @course-suite/web build`, then `size`, gzip -9): this package
with the engine packages it uses (doc-ops, format, host, jobs, project, zip) is 70.3 KB gzipped,
script and style, on top of React (65.8 KB), React Aria (121.1 KB) and the kit (25.2 KB);
`editor.html` loads 284.0 KB in all. The block previews (the player's block renderer and style
sheet, 16.3 KB) load with the first lesson opened, and the player chunk of the course preview
(67.0 KB) with the first preview. On top of M2-12 and M2-13, the theme panel and the author's fonts
(M2-17) add 11.0 KB to this package, 1.7 KB to the kit and 6.5 KB to the player chunk: 12.7 KB more
for `editor.html`. The bundled fonts (24 files, 451 KB, already compressed) load only when a page
draws text in them. No dependency.

Limits: a media file may be at most 2 GiB (the spec allows 5 GB, UI-BLOCKS-EDITOR-R34), as a
project file holds 4 GiB in all without ZIP64 and is held in memory while saved; a file picked in
the open dialog is read before its size is known. The preview sends every media file to its frame
on each update, so very large videos make updates slow.
