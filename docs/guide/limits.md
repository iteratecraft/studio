# What 0.1 does not do yet

[User guide](README.md) › What 0.1 does not do yet

Course Suite 0.1 is the first version. These are its known limits, and what later versions are
planned to bring. Plans can change; the release notes of each version say what it really adds.

## The app

- **Windows only.** Version 0.1 runs on Windows 10 and 11, 64-bit. Versions for macOS and Linux
  come later.
- **Not code-signed.** Windows warns before you install it; check the download's checksum
  ([Install and uninstall](install.md)).
- **One person per course.** There is no shared editing, commenting or review yet, and no server
  edition: those come in later versions.
- **A working name.** "Course Suite" may still change before the first public release. A new name
  would come with a new install folder; your course files would not be affected.
- **English only.** The app's own words are in English.
- **No folders in Your courses.** Courses are one list, with search, sort and a type filter.

## Blocks

These block types are listed in the block library as **Not available yet**:

- scenario, sorting activity and timeline, and bar, line and pie charts: planned for version 0.2;
- survey;
- questions drawn from a bank, and saved block sets (block templates): with the team libraries of
  a later version;
- a project from the Slides app, a code block and a custom canvas: later versions;
- AI text and AI image: later versions.

Also not in 0.1:

- Formatted text has a fixed set of styles (normal text, headings, bold, italic and so on): no
  choice of font, size or colour for a word or a paragraph yet (planned for version 0.2).
- Lesson templates of your own, shared with a team, come with the team libraries of a later
  version. The four built-in lesson templates are there.

## Pictures, audio and video

- Pictures in blocks cannot be cropped or aligned yet (version 0.2); the theme's cover, logo and
  header pictures can be cropped.
- Videos and embeds take the block's content width; their own width setting, and video chapters,
  are planned for version 0.2.
- Narration is added as an audio file; recording it in the app is planned for version 0.2.
- Captions are WebVTT files only. SRT and other caption formats come later, as do captions and
  narration made by AI.
- A file can be at most 2 GB.
- A code snippet shows its code in one colour, without syntax colours.

## Publishing

- Five outputs: SCORM 1.2, SCORM 2004 (4th edition), xAPI, cmi5 and a web package. There is no PDF
  output, no publishing to a review site and no sending a copy of a course to another author yet;
  those come in later versions.
- No choice of SCORM 2004 edition (2nd and 3rd), no option to hide the learning system's own
  controls, and no sending of results to a learning record store of your own from a web package
  or alongside a learning system: planned for version 0.2.
- Version 0.2 is planned to keep a version of the course each time you export, and to let you
  name versions yourself. In 0.1, keep copies with **Save as** or **Duplicate**.
- Learning systems receive the course's result and each answer to a quiz question, but not the
  answers to knowledge checks inside a lesson.
- The words the course player shows learners (buttons and messages) cannot be changed or
  translated yet. Translating a course is planned for version 0.2.

## Checks

- The editor checks colour contrast as you pick colours, flags pictures without alt text and
  headings that skip a level, and lists problems before you export. A full accessibility checker
  for the whole course is planned for version 0.2.
