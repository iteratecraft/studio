# Keyboard use

[User guide](README.md) › Keyboard use

Course Suite is made to be used with the keyboard alone, as well as with a mouse. The editor
announces to screen readers what changed when you add, move, copy or delete something.

## Moving around

| Keys | What they do |
|---|---|
| **Tab**, **Shift+Tab** | Next or previous control |
| **Enter**, **Space** | Press a button; **Space** turns a switch or a tick box on or off |
| **Arrow keys** | Move within a group: the tools of a toolbar, the items of a menu or list, tabs, the options of a choice |
| **Escape** | Closes a menu, a list or a window, and takes you back to where you were |
| **F6** | Moves to a notice, such as the one that offers **Undo** after a delete; **Enter** then acts on it |
| **Alt** | Moves to the window's menu bar (**File**, **Edit**, **Window**, **Help**); then the arrow keys and **Enter** |

A button that shows only an icon shows its name when you move to it. Within a choice list, typing
the first letters jumps to the matching option.

## Everywhere in a course

| Keys | What they do |
|---|---|
| **Ctrl+S** | Save the course file, even while you type in a text field |
| **Ctrl+Shift+S** | Save as a new file |
| **Ctrl+Z** | Undo (outside text fields) |
| **Ctrl+Y** or **Ctrl+Shift+Z** | Redo (outside text fields) |
| **Escape** in a text field | Take back what you typed since you entered the field |

## Your courses

| Keys | What they do |
|---|---|
| **Arrow keys** | Move between courses |
| **Enter** | Open the course |
| **Ctrl+A** | Select every course on the page |
| **Escape** in **Search by title** | Clear the search |

## Outline and blocks

| Keys | What they do |
|---|---|
| **Enter** in **New lesson or section** | Add a lesson |
| **Shift+Enter** in **New lesson or section** | Add a section header |
| **Enter** on a drag handle, **arrow keys**, **Enter** | Move a row or a block; **Escape** puts it back |
| **Ctrl+C** on a block's row | Copy the block |
| **Ctrl+V** on a block's row | Paste copied blocks below it |
| **Space** in **Manage blocks** | Select or unselect a block |
| In the block library: type, **Tab**, **arrow keys**, **Enter** | Search the types, move into the list, pick one, add it |
| **Arrow keys** on a marker of a labelled image | Move the marker by 1 %; with **Shift**, by 10 % |

## Formatted text

| Keys | What they do |
|---|---|
| **Ctrl+B** | Bold |
| **Ctrl+I** | Italic |
| **Ctrl+U** | Underline |
| **Ctrl+Shift+X** | Strikethrough |
| **Ctrl+K** | Link |
| **Alt+F10** | Move to the text's tools; **Escape** goes back to the text |

## Caption editor

| Keys | What they do |
|---|---|
| **Enter** | Split the caption at the cursor, or at its end add a caption after it |
| **Backspace** at the start of a caption | Join it to the caption before |
| **Delete** at the end of a caption | Join the caption after to it |

## In the preview

The preview works as it will for learners: **Tab** and **Shift+Tab** move between the course's
controls, **Enter** presses them, **Space** plays and pauses media, and **Escape** closes an open
marker or the course menu. In a microlearning that moves in steps, the **Up** and **Down arrow
keys** go to the previous and next step.
