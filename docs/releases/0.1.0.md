# Course Suite 0.1.0

The first version of Course Suite: a desktop app for **Windows 10 and Windows 11 (64-bit)** to
write online courses and export them for a learning system or a website. It is free and open
source.

The [user guide](../guide/README.md) explains every step.

## What you can do

### Make and keep courses

- Start a blank course, a blank microlearning (a short course of one lesson), or a course from one
  of two templates with placeholder text that says what to write.
- Keep each course in one `.crs` file, wherever you choose, with all its pictures, audio, video and
  fonts inside. Copy it, back it up or send it like any file.
- Find your courses on one screen: search by title, sort, filter by type, grid or list.
- Duplicate, rename and delete courses. Deleting only takes a course off your list: the app never
  deletes a course file.
- Lose at most a few seconds of work: the app keeps your changes as you go and offers them back
  after a crash or a power cut.

### Write lessons

- Plan the course in an outline of lessons, quizzes and section headers. Reorder by dragging or
  with the keyboard, duplicate, or copy a lesson to another course.
- Build each lesson from blocks: paragraphs and headings, columns, tables, statements and notes,
  quotes, lists and checklists, images and galleries, audio, video, embedded videos, files to
  download, code snippets, accordions, tabs, labelled images, processes, flashcards, buttons,
  dividers and continue buttons.
- See each block as learners will, beside the fields you type in.
- Give any block a background colour or picture, padding, a width and an entrance animation, and
  add narration to it.
- Copy and paste blocks between lessons and courses, or work on many blocks at once.
- Undo and redo every change.

### Pictures, audio and video

- Add files with a button or by dragging them in. Large pictures are made smaller for you, unless
  you keep the original.
- Add any common audio or video file: files that not every browser can play are converted on your
  computer, with a free converter the app downloads once, after asking you.
- Add captions to videos (WebVTT files), and edit them in the app.
- Embed videos from YouTube, Vimeo, Loom or Dailymotion. They load only when a learner plays them.
- Write alt text for every picture, or mark it decorative; pictures without either are flagged.

### Questions and quizzes

- Ask single choice, multiple response, fill-in-the-blank and matching questions, inside a lesson
  or in a quiz lesson with a passing score.
- Choose feedback, retries, a time limit, random order and what learners see after each answer.
- Make learners answer, pass, or finish what they are doing before they go on.

### The look of the course

- Pick a layout style, a colour, the cover page, lesson headers and fonts, and see each change in
  the course straight away. The app checks that text stays readable.
- Use the device's own fonts, eight bundled open-licence fonts, or fonts of your own.
- Choose how learners move through the course: a sidebar, compact or overlay menu, lessons in
  order or free, course search, and previous and next buttons. A microlearning can move in steps.

### Preview and export

- Try the course as a learner, at computer, tablet and phone width.
- Export it as SCORM 1.2, SCORM 2004 (4th edition), xAPI, cmi5 or a web package, with the course's
  completion rule and the result it reports. The app lists anything to fix before you export, and
  you can keep working while it builds.
- Exported courses carry their own fonts and player, and connect to nothing but the learning
  system that opens them (and the sites of any videos you embedded).
- The packages are tested in Moodle (SCORM 1.2), ILIAS (SCORM 2004), an open-source learning record
  store (xAPI) and the cmi5 test suite.

### Keyboard and updates

- Work with the keyboard alone or with a mouse, with shortcuts for saving, undo, redo and text
  formatting.
- The app checks for a new version once a day (you can turn that off), and installs one only when
  you agree. If a course has unsaved changes, it asks you about them first.

## Known limits

- Windows only; macOS and Linux versions come later.
- The installer is not code-signed, so Windows warns before it runs. Check its checksum first
  (below).
- One author per course: no shared editing, comments or review yet.
- Some block types are listed but not available yet: AI text and images, scenario, sorting
  activity, timeline, charts, survey, questions from a bank, saved block sets, Slides projects, code
  block and custom canvas.
- Pictures in blocks cannot be cropped or aligned yet. Narration is added as a file, not recorded
  in the app. Captions must be WebVTT files.
- A media file can be at most 2 GB.
- The words the player shows learners (buttons, messages) cannot be changed or translated yet.
- Learning systems get the result of the whole course, not each answer.
- "Course Suite" is a working name and may change before the first public release.

[What 0.1 does not do yet](../guide/limits.md) has the full list and what is planned next.

## Install

1. From this release, download `Course-Suite_0.1.0_x64-setup.exe` and `SHA256SUMS.txt`.
2. Check the download. In PowerShell, in the folder you downloaded to:

   ```powershell
   Get-FileHash .\Course-Suite_0.1.0_x64-setup.exe
   ```

   The **Hash** it prints must match the checksum at the start of the line in `SHA256SUMS.txt`
   (PowerShell prints capital letters; the file has small ones, which is the same). If they differ,
   do not run the file.
3. Run the installer. If Windows shows **Windows protected your PC**, choose **More info**, then
   **Run anyway**.
4. It installs for your Windows account only, without administrator rights, and adds **Course
   Suite** to the Start menu.

To remove it: Windows **Settings**, **Apps**, **Course Suite**, **Uninstall**. Your course files
stay where you saved them.

## The checksum line

`SHA256SUMS.txt` holds one line for the installer: its SHA-256 checksum as 64 small letters and
digits, a space, a `*`, and the file name:

```text
<64 letters and digits> *Course-Suite_0.1.0_x64-setup.exe
```
