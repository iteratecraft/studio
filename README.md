# Course Suite

Course Suite is an open-source app for writing online courses and exporting them for learning
systems (SCORM 1.2, SCORM 2004, xAPI, cmi5) or any website. Version 0.1 is a desktop app for
Windows 10 and 11.

## For course authors

- [User guide](docs/guide/README.md): installing the app, then every step from a first course to
  an exported package.
- [Release notes for 0.1.0](docs/releases/0.1.0.md): what this version does, its known limits,
  and how to check the download.
- Downloads: the [releases page](https://github.com/iteratecraft/studio/releases).
